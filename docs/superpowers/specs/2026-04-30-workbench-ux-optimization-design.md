# 工作台用户体验优化 — 设计文档

**日期**：2026-04-30  
**版本**：v1.0  
**状态**：草稿  

---

## 1. 概述

### 1.1 目标

对 NovelAgent 工作台进行全面用户体验优化，覆盖界面、交互和功能三个维度。以日常使用体验为优先，在现有架构基础上做增量改进，不动整体结构。

### 1.2 范围

- ✅ 写作面板重构（核心）
- ✅ 大纲面板优化
- ✅ 章节大纲面板优化
- ✅ 灵感面板优化
- ✅ 顶部布局优化（WorkbenchLayout）
- ✅ 全局交互增强（快捷键、空状态、错误处理）
- ❌ 不新增后端 API
- ❌ 不新增版本历史、导出等大型功能
- ❌ 不动人物面板和关系面板

### 1.3 设计原则

1. **日常使用体验优先**：先优化最高频的写作场景
2. **增量改进**：在现有架构上打磨，不推倒重来
3. **减少噪音**：去掉无用元素（写作辅助Tab），折叠低频内容
4. **一致性**：6 个面板统一交互模式（标题栏、工具栏、保存按钮）

## 2. 写作面板重构

### 2.1 当前问题

- AI 助手面板 350px 宽，其中"写作辅助"Tab 是纯占位文字，无实际 AI 功能
- 章节列表缺少状态标记
- 预览/编辑切换按钮不够显眼
- 生成过程中无进度反馈
- 无快捷键支持
- 保存反馈仅 toast 提示

### 2.2 优化设计

#### 2.2.1 三栏布局调整

| 栏位 | 现状 | 优化后 |
|------|------|--------|
| 左侧章节列表 | 176px，固定 | 160px，可折叠为 40px |
| 中间编辑器 | flex-1 | flex-1（空间更大） |
| 右侧面板 | 350px，双 Tab | 240px，仅审核功能 |

**去掉写作辅助 Tab**：系统全程使用 AI 生成，写作辅助无实际意义。右侧仅保留审核功能，宽度从 350px 缩减到 240px。

#### 2.2.2 章节列表增强

- 增加状态图标：
  - ✅ 绿勾 — 已生成正文
  - ⏳ 橙色 — AI 生成中
  - 📋 蓝色 — 大纲已确认（待生成）
  - 无图标 — 未开始
- 显示每章字数
- 增加折叠按钮（◀ 收起为 40px 仅显示图标）
- 底部显示进度汇总：「已写 2 / 12 章」

#### 2.2.3 编辑器模式

- **默认预览模式**：AI 生成后以 HTML 渲染展示
- **编辑模式**：点击工具栏按钮切换到 TipTap 富文本编辑器
- 预览/编辑切换按钮放在工具栏显眼位置，带有图标（👁 预览 / ✏️ 编辑）

#### 2.2.4 AI 生成增强

- 生成中显示：
  - 实时字数统计（跟随流式文本增长）
  - 进度指示器（如果后端返回进度信息）
- 生成失败时：
  - 保留已生成的部分内容
  - 显示「重试」按钮

#### 2.2.5 快捷键

- `Ctrl+S / Cmd+S` — 保存
- `Ctrl+Enter / Cmd+Enter` — 触发 AI 生成

#### 2.2.6 保存反馈

- 保存成功后按钮短暂显示「✅ 已保存」（约 1.5s 后恢复）
- 配合 toast 提示

#### 2.2.7 审核面板精简

审核面板（240px）去掉了写作辅助 Tab，仅保留审核功能：

- **未审核状态**：显示「开始审核」按钮 + 引导文字
- **审核中**：显示加载状态
- **审核通过**：绿色结果卡片 + 反馈
- **审核未通过**：红色结果卡片 + 反馈 + 问题列表
- 审核结果点击问题可高亮对应段落（如果技术可行）

## 3. 大纲面板优化

### 3.1 表单分组布局

将线性的表单字段重组为三张卡片：

1. **📋 基本信息** — 标题 + 建议章节数（并排）
2. **📝 内容概述** — 简介 + 概述
3. **📍 情节节点** — 列表 + 添加/删除按钮

每张卡片带颜色图标和标签，视觉层次清晰。

### 3.2 AI 分析区（手动触发）

改为用户主动触发的交互模式，三种状态：

| 状态 | 展示内容 |
|------|---------|
| **未触发** | 空状态引导文字 + 「✨ AI 分析大纲」按钮 |
| **分析中** | 进度条动画 + 流式输出 + 「取消」按钮 |
| **分析完成** | 建议卡片（采纳/忽略）+ 「🔄 重新分析」按钮 |

建议卡片类型：💡 情节建议、👤 角色发展、🌍 世界观

### 3.3 其他优化

- AI 分析区可折叠（点击标题收起），宽度 240px
- 顶部显示确认状态徽章（已确认/未确认）
- 已确认后确认按钮禁用
- 支持 Ctrl+S 保存

## 4. 章节大纲面板优化

### 4.1 批量生成进度增强

- 进度条改为渐变色（蓝→紫）
- 实时显示当前正在生成的章节名称：「⏳ 正在生成第 3 章『冲突』...」
- 进度条下方显示已完成章节列表缩略
- 支持取消批量生成

### 4.2 一键确认

- 侧边栏底部增加「✅ 一键确认 (N)」按钮
- 仅确认所有未确认的章节
- 确认后按钮自动消失

### 4.3 章节状态精细化

在左侧章节列表中增加状态标记：
- ✅ 绿勾 — 大纲已确认
- 📝 蓝色 — 已写正文
- ⏳ 橙色 — 生成中

### 4.4 右侧详情面板

- 确认状态显示
- 新增：已写正文字数
- 新增：章节大纲统计卡片（已确认数 / 总数 / 总目标字数）

### 4.5 快捷键

- Ctrl+S 保存

## 5. 灵感面板优化

### 5.1 步骤引导

顶部增加步骤引导条：

```
① 必填信息 (7)  →  ② 高级设定
```

降低 14+ 字段一次性全部展开的心理压力。

### 5.2 表单重组

| 区域 | 内容 | 状态 |
|------|------|------|
| 📋 核心设定 | 目标读者、年代、小说类型、目标字数、每章字数 | 必填，始终展开 |
| 🎯 核心主题 | 核心主题选择 | 必填，始终展开 |
| 📝 高级设定 | 叙事视角、世界观、流派、人设、金手指、风格偏好 | 选填，默认折叠 |

高级设定折叠状态下显示「已填 N 项」提示。

### 5.3 Prompt 模板区优化

- **布局比例**：表单区与 Prompt 区从 50:50 改为约 70:30，Prompt 区宽度缩小到 280px
- **新增功能**：
  - 「📋 复制」按钮 — 一键复制 Prompt 到剪贴板
  - 「↺ 重置」按钮 — 恢复自动生成的模板（保留）
  - 快捷填充模板（三个预设）：
    - 🗡️ 废柴逆袭模板（男频玄幻）
    - 💕 甜宠逆袭模板（女频言情）
    - 🚀 星际科幻模板

### 5.4 确认按钮

- 底部居中显示，使用主色调（紫色）
- 附带引导文字：「确认后自动跳转到大纲生成」

## 6. 顶部布局优化（WorkbenchLayout）

### 6.1 当前问题

返回按钮「← 返回」放在项目 Header 左上角，与全局 Logo 紧邻，视觉层次混乱。"返回"语义不够明确。

### 6.2 优化设计

| 改动项 | 现状 | 优化后 |
|--------|------|--------|
| 按钮位置 | 左上角 | 右上角 |
| 按钮文字 | 「← 返回」（灰色链接） | 「📋 项目列表」（主色实心按钮） |
| 左侧内容 | 返回 + 项目名 + 进度条 | 仅项目名 + 渐变进度条 |
| 进度条 | 80px 宽，细条 | 120px 宽，渐变色 |

布局模型：

```
[Logo · Nav ··· admin]          ← 全局 Header
[项目名称 ████░░░░ 35% ··· 📋 项目列表]  ← 项目 Header（左右分区）
[💡规划 | ✏️创作]               ← Tab 导航
```

## 7. 全局交互增强

### 7.1 快捷键体系

| 快捷键 | 作用域 | 功能 |
|--------|--------|------|
| `Ctrl+S` / `Cmd+S` | 全局 | 保存当前面板内容 |
| `Ctrl+Enter` / `Cmd+Enter` | 写作面板 | 触发 AI 生成 |

### 7.2 Tab 切换状态保留

当用户在「规划」和「创作」Tab 之间切换时，各面板保留其编辑状态，避免丢失未保存内容。

实现方式：`workbenchStore` 中增加面板状态缓存。

### 7.3 空状态引导

所有面板增加友好的空状态提示：

| 面板 | 空状态提示 |
|------|-----------|
| 写作面板 | 「选择章节开始写作」 |
| 大纲面板 | 「点击 AI 生成大纲开始」 |
| 章节大纲面板 | 「请先生成小说大纲，再生成章节大纲」 |
| 灵感面板 | 显示表单（本身就是引导填写） |

### 7.4 生成错误处理

- AI 生成失败时不丢弃已收到的流式内容
- 显示「重试」按钮（重新发起生成请求）
- 显示错误信息详情

### 7.5 加载状态统一

- 统一使用 Skeleton 骨架屏，替代简单的「加载中...」文字
- 使用 shadcn/ui 的 Skeleton 组件
